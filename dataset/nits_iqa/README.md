# NITS-IQA sample files

This directory contains a partial set of NITS-IQA files and saved metric results. The upstream dataset paper describes 9 reference images and 405 distorted images; the `ref/` and `que/` directories in this repository currently contain only 9 files each. The checked-in score CSV has 405 data rows, so it cannot be fully regenerated from the image files included here.

Dataset reference: Jayesh Ruikar and Saurabh Chaudhury, “NITS-IQA Database: A New Image Quality Assessment Database,” *Sensors*, 2023, 23(4), 2279. DOI: <https://doi.org/10.3390/s23042279>.

Please cite the dataset paper when using these files. Confirm the dataset provider's terms before redistributing the image files or MOS workbook. The repository's AGPL-3.0 license applies to source code and does not change third-party dataset terms.
