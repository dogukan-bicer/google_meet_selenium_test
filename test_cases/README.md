# Test case catalog

This directory contains 30 scenario folders (`TC_01` through `TC_30`). Each folder has its own `README.md` describing the scenario, procedure, expected behavior, and any supplied sample media.

The scenarios cover meeting join/leave behavior, camera and microphone controls, image and audio quality, network and stability conditions, receiver consistency, frame-rate behavior, and related checks. The supplied files are test inputs and examples; their presence does not mean every scenario has been executed on every platform or that all expected results have been independently reproduced.

Use the scenario README as the source of its individual steps. Check the source and redistribution permissions for media before publishing or reusing it outside this repository.
