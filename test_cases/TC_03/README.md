# TC_03 - 

## Test Adımları
1. Bir toplantıya katıl
2. Mikrofon kaynağı olarak sabit_frekans.wav dosyasını seç
3. Mikrofonu aç
4. Ses seviyesi ölçüm aracı ile mevcut ses seviyesini kaydet
5. Mikrofonu sessize al
6. Ses seviyesinin 0'a düştüğünü doğrula
7. Mikrofonu tekrar aç
8. Ses seviyesinin -30dB üzerinde olduğunu doğrula

## Beklenen Sonuç
Sessize alındığında: ses yok, Açıldığında: ses seviyesi > 30dB
